# MTG Judge

An unofficial Magic: The Gathering rules judge, game tracker and Commander deck guide.

**Live site:** https://robbieagassociates.github.io/mtg-judge/

- Search the full Comprehensive Rules (effective September 25, 2026), every card's official text and rulings, and Commander combos.
- Track a game move by move and check each move against the rules.
- Browse four analyzed Commander decks with card images, stats and deck ideas.

On this site the Judge runs in lookup mode: answers are built from the saved rules, rulings and card data, without AI-written explanations.
